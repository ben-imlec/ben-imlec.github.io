#05 · Yapay zekaya eklenen beceri

Claude'a Instagram becerileri ekle

Instagram Agent Skill, Claude'a eklenen 13 hazır beceri: video senaryosu, ilk cümle puanı, açıklama denetimi, haftalık plan, profil karnesi, alanında tutan videoları bulma (ig-viral), tek videodan bir haftalık içerik (ig-repurpose) ve daha fazlası. Tek başına çalışan bir program değildir, Claude gerekir. Gönderiyi senin yerine paylaşmaz.

Ücret
Beceriler ücretsiz (MIT lisansı). Claude'un ücretsiz hesabına da yüklenebilir. Claude Code kullanacaksan ücretli bir Claude planı ya da API kredisi gerekir.
Gereken
Bilgisayardan claude.ai ya da Claude Code. Telefon uygulamasından yükleme konusunda resmî bilgi bulamadım.
  1. Dosyaları indir

    GitHub sayfasında Code › Download ZIP'e bas ve dosyayı aç. Beceriler skills klasöründe.

    GitHub sayfası
  2. Ücretsiz hesapla: önce ayarı aç

    claude.ai'de Settings › Capabilities bölümünde kod çalıştırma ve dosya oluşturma ayarını aç.

  3. Beceriyi yükle

    skills içindeki bir klasörü (ör. ig-reel) kendi başına ZIP yap. Customize › Skills › + › Create skill › Upload a skill yolundan yükle ve aç. Her beceri için tekrarla; hepsini yüklemen gerekmez.

    Claude beceri sayfası
  4. Claude Code kullanıyorsan

    Aşağıdaki mesajı Claude Code'a yapıştır, kurulumu o yapsın.

    https://github.com/Jakeschincariol/instagram-agent-skill Bu becerileri kur: skills klasöründeki ig-* klasörlerini ~/.claude/skills/ içine kopyala. Kurmadan önce dosyalara bakıp ne yaptıklarını bana kısaca anlat. Sonra ig-reel becerisinin çalıştığını doğrula.
  5. Türkçe kullan

    Konunu yaz ve Türkçe iste.

    ig-reel becerisini kullan. Konum: [konunu yaz]. 30 saniyelik bir Reels senaryosu hazırla. Çıktının tamamı Türkçe olsun. İlk cümle puanlaması İngilizceye göre, o yüzden puanı değil, gerekçelerini Türkçe olarak değerlendir.

Dikkat. Tutan videoları bulan ig-viral, Instagram'da senin kullandığın tarayıcıdan okur; hesap bilgini istemez, düz sohbette tarayıcı erişimi olmayabilir. İlk cümle puanlayıcısının kelime listeleri İngilizce; Türkçe cümlede verdiği puana güvenme. Yapımcının kendi ölçümüne göre zayıf ilk cümleleri iyi yakalıyor (10 zayıf örneğin 9'u, 74 gerçek YouTube Shorts ile karşılaştırılmış) ama iyi iki cümleden hangisinin tutacağını ayırt edemiyor (0,56; yazı tura 0,50). Beceriler gönderi paylaşmaz, yorum yapmaz; son kararı sen verirsin. Her üçüncü taraf beceride olduğu gibi yüklemeden önce dosyalara göz at.
